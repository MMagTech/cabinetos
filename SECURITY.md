# Security

**Report a security problem privately**, not in a public issue: on this
repository's Security tab, choose "Report a vulnerability". It stays
between you and the maintainer until he publishes it.

A security problem is anything that lets someone reach what they should not:
a RomM sign-in, a console's files or shell, the update path, or another
person's saves. Examples: the console sending its RomM sign-in somewhere other
than the player's server, or an update installing without a valid signature.

Say which version (Settings, About, Version), the machine, and how to make it
happen. Leave the diagnostic report out unless asked: it is made for public
issues and has private details replaced, but a security report needs only the
steps.

Only the latest version gets fixes, and a fix ships as an ordinary update.
