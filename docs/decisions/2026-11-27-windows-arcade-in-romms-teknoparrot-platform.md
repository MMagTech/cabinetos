# Windows arcade games go under RomM's own TeknoParrot platform

- **Decided:** Every Windows arcade game, whatever its board, goes under RomM's own `teknoparrot` platform: a folder named `teknoparrot`, which RomM knows by itself, or any folder the library's owner maps to it in RomM. The console knows these games by that platform (`arcadematch::isWindowsSlug`), takes it as an arcade platform, and puts its games in the Arcade tile. The Windows files go in as that platform's firmware. Each game is a zip or 7z of its folder with its `<gameid>.windowsloader` file inside (an unpacked folder still plays), and comes down as one file, as a Lindbergh game does. The feature keeps the name Windows Arcade on the console and in the wiki.
- **Date:** 2026-11-27 (MMagTech, #762)
- **Why:** These are the games RomM files under TeknoParrot, and it is where people already keep them. RomM 5.5.0-beta.1 has `teknoparrot` as a platform of its own and counts it among its arcade platforms (`ARCADE_PLATFORMS`), so a metadata source with no platform for it looks the games up as arcade games, and their covers come without a folder mapping. The loader knows each game's board from its ID, so a folder per board would tell the console nothing and would ask the owner to sort by board. These games hold up to 12,252 files, and RomM is slow with a folder of thousands.
- **Numbers:** #762, "Windows Arcade: games from Windows-based arcade boards, in windowsarcadeloader".
- **Replaces:** the plan's own folder for these games, `windows-arcade` (#762, 2026-11-26): RomM does not know that name, so it made a platform of its own with no covers, apart from the other arcade games.
