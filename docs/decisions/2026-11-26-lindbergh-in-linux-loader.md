# Lindbergh plays in Linux Loader's own AppImage, unpacked into the image

- **Decided:** Sega Lindbergh games play in Linux Loader v3.0.15, its developers' own AppImage pinned by checksum and unpacked into the image with every library the image has itself taken out, its own Mesa among them, so the image's 32-bit Mesa draws; never patched, drawing with OpenGL, and started with no network like every emulator. The 32-bit packages it uses are named in the image, Mesa among them, so it never rests on Steam, with pipewire-alsa's 32-bit half. One settings file and one controls file, written whole at every start, the same for every game: the loader's own defaults and pad layout but for the console's choices (Coin on Back, Test and Service off, no free play, the picture's height by the level with the width from the game's own shape, the save files in the person's folder, no network patches). Exit is the loader's own quit, ExitGame, which the console presses on player 1's virtual controller's Guide. Each game is its hard drive's folder, kept in RomM as a zip or 7z of it (an unpacked folder still plays), and comes down as one file and is unpacked; the program inside it chooses, not its name. Saves go to RomM in its arcade form. Listed in the wiki as experimental.
- **Date:** 2026-11-26 (the plan, MMagTech, #620); a game as a zip or 7z, and as one file to download, 2026-11-26 in the build.
- **Why:** The AppImage is what the trial of 2026-11-26 ran, and building the loader here would need a 32-bit builder and still ship the prebuilt libraries its repository carries; for a player the two play the same. Its own Mesa does not know the Radeon 890M. The loader has no Vulkan renderer, and Zink measured the same speed with more load and Hummer's sky broken, so OpenGL is the measured case. It has no SIGTERM handler and writes the board's memory with no flush, so only its own quit keeps the last write, and a player's Guide never reaches a game. RomM lists every file of a folder: Hummer Extreme's TeknoParrot copy holds 124,777, so fetched file by file its list alone was 104 MB, against one zip of 3.04 GB in 116 s on the write-test server. A zip or 7z is one file to RomM: as a folder, Hummer's start asked RomM about save channels on all its files, some 1,500 requests, over 5 minutes, and its entry ran past the console's 30 s for a request; zipped, RomM's entry was 3 MB in half a second. RomM 5.5 could not store the list of a zip of 124,799 files, so a TeknoParrot copy's `drv/nvidia` (110,019 NVIDIA driver files the loader never uses; Hummer boots without them) comes out first. The 32-bit pipewire-alsa is Fedora's build of the image's PipeWire version, pinned, since Fedora's repositories keep only their newest.
- **Numbers:** #620, "Sega Lindbergh: The House of the Dead 4 and more with Linux Loader"; #575, "Sinden light guns: plug in and play gun games", which the gun games wait for.
- **Replaces:** none.
