# A RomM account is one LinkUp person on every console, with one code

- **Decided:** A console has one LinkUp server, added by the admin and shared by everyone on it, and only the server's owner makes friends. One RomM account is one person on every console they sign in on: shown once, never in their own friends list, with one set of friends, by their RomM username, with their server's name beside it when two share it. Each person has one code: the invite they used, or the owner's own-console code, becomes theirs, never expires, and works for no other account; another console, or a reinstall, joins with it while signed in as them. The owner looks after people, not consoles: Change code signs the person out of every console until the new code is typed on each, and Remove takes them, their friends and their code. A knock rings the console they signed in on, or came back to from Offline, last. Offline they choose holds on all their consoles until they choose Online; a console's own reasons for Offline stay with that console. A console taken off the server types a code again from the LinkUp tab's line or from Settings' Server panel, with the PIN as for adding a server.
- **Date:** 2026-11-12
- **Why:** People play on more than one console. One account as two people looked like two friends with the same name, could be knocked on at a console nobody was at, and could invite itself. A code for the person means a second console or a reinstall needs nothing from the owner. The `account` a console sends is not a secret, so the code is what proves who joins, and it works for nobody else. The owner thinks in people, and one press signs out a person whose code was seen: the server cannot tell their own console from one that used the old code, so each console proves itself with the new one. The console used last is the one somebody is at. Offline is a person not wanting to be on show, so it follows them, while a console left idle or asleep says nothing about the person. A removed console took six steps to come back, through Leave; the person reads the line on the LinkUp tab, and Settings is where a server is looked after, so both offer the code.
