# The Windows files a Windows arcade game needs come from the library's owner, through RomM

- **Decided:** CabinetOS never ships and never downloads Microsoft's runtimes and DirectX parts, NVIDIA's PhysX or the other installers windowsarcadeloader's Windows setup is made from. The library's owner brings them, like a BIOS: CabinetOS's admin script downloads every file any game in the pinned loader needs (28 files, 615 MB at the pin), checks each against its checksum, and packs them into one file, which goes into RomM's firmware for Windows Arcade. The console builds the Windows setup from that file once, with no network. The list of files is never typed: it is read in CI from the pinned loader's own lists of winetricks verbs and from winetricks' own addresses and checksums. Until the file is in RomM the games show, and Play says the Windows files are missing, as a missing BIOS does. The same script writes each game's `<gameid>.windowsloader` file, the loader's own way of naming a game and its program; a game without one is not supported.
- **Date:** 2026-11-26 (MMagTech, #762)
- **Why:** Their terms let a person install these files and let a program's developer ship them with that program; CabinetOS wrote neither the games nor the programs, and the loader does not ship them either. The console connects only to the player's RomM and to GitHub, and the files come from eleven sites, several of them unofficial mirrors. Five of them are named `vcredist_x86.exe`, so they travel as one file in winetricks' own cache layout. The whole list, not only the games tried, because a setup missing one game's file fails for that game with no network to fetch it. No download carries a game's `.windowsloader` file and no list gives its program: of 418 profiles, 280 name a program only in a comment.
- **Numbers:** #762, "Windows Arcade: games from Windows-based arcade boards, in windowsarcadeloader".
- **Replaces:** none.
