# A Wii Remote starts only Wii games, and HOME held leaves any game

- **Decided:** A press from a Wii Remote starts only Wii games. On any other game, Play, Play from a save state and Home's Resume card show a toast, *This Remote only plays Wii games*, and nothing starts. Holding HOME on a Remote for a second opens the pause menu in every game, not only Wii games. Nothing is greyed out for having no pad. While only Wii Remotes are on (the top bar shows W's and no P's), every game that is not a Wii game says *Needs a controller* after its name, on Home, in the grids and in Search, and the note goes as soon as another controller comes on; a game greyed for a reason of its own keeps that reason.
- **Date:** 2026-10-24; the *Needs a controller* note 2026-10-25.
- **Why:** With only a Remote on, a player could start a game the Remote can't play and leave only by the power button (a Discord report, 2026-10-23). A game you can't play with what you hold not starting fits the rest of the console. The rule goes by which controller pressed, not which controllers are on: a Remote's presses carry a made-up pad id no real pad has, so pads, keyboards and Remote Play devices are never stopped, and a pad that is asleep greys nothing. HOME held still gets a Remote out of a game someone else started. The note says it before Play does, to someone browsing with the Remote a Wii game was started with; it goes by which controllers are on, as the top bar does, because it greys and hides nothing, so a pad asleep costs only a note that a press on the pad clears.
- **Numbers:** #571, "Holding HOME on a Wii Remote opens the pause menu in every game"; #589, "While only Wii Remotes are on, other games say \"Needs a controller\"".
- **Replaces:** none.
