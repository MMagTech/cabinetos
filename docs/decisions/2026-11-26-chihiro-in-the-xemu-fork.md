# Chihiro plays in Tovarichtch's xemu fork, built here at a pin

- **Decided:** Sega Chihiro games play in xemu-chihiro, Tovarichtch's fork of xemu, a program of its own built into the image from commit 98fbd75 (the commit Batocera 44 builds), never patched, drawing with Vulkan and started with no network like every emulator. Each game is one converted image, `<set>.bin`, made once by the library's owner with chihiro-netboot; the console never converts one. `chihiro.zip` and `seganetw.zip`, MAME's, are its BIOS, both needed for every game. No save states; holding Start does nothing; Test and Service off. A save of one file goes to RomM as that file, several as a zip with no folders. The light-gun games wait for #575.
- **Date:** 2026-11-25 (the plan, MMagTech); the BIOS for every game and the save's form 2026-11-26, in the build.
- **Why:** xemu itself has no Chihiro board (xemu-project/xemu#2761) and the fork's only Linux build is an AppImage, so a pinned build keeps one emulator for everyone, as for Model 2 and Model 3. On the reference console all six games tried held 60 frames a second at 4x, and the fork needs no change for anything the console asks of it. MAME's list gives every Chihiro set the network board, and without its firmware OutRun 2 Special Tours stops on the board's own "Error 14" screen, so one rule asks for both zips rather than a list of games. RomM takes an arcade save as the emulator's own files ([arcade-saves-in-romms-form](2026-11-25-arcade-saves-in-romms-form.md)).
- **Numbers:** #619, "Sega Chihiro: Virtua Cop 3 and The House of the Dead III in the xemu fork"; #575, "Sinden light guns: plug in and play gun games".
- **Replaces:** none.
