# A light gun's rear right button reaches a game as it is let go

- **Decided:** in a game, a tap of a Sinden light gun's rear right button
  (coin, or Select) reaches the game as the button is let go, held there for
  100 ms. Held for a second instead, it opens the pause menu and the game
  gets nothing. Held under the pause menu, it closes it. Out of a game the
  button does nothing.
- **Date:** 2026-11-27
- **Why:** #575 rule 10 gives the one button two jobs, a coin and the pause
  menu. Passed to the game as it went down, every pause would first drop a
  coin, and in an arcade game a credit is spent. Sent on release, a tap is
  the same coin a little later, and a hold is only the pause. A Wii Remote's
  HOME is passed as it goes down because a Wii game has its own HOME menu; a
  coin has no such use.
- **Numbers:** #575, "Sinden light guns: plug in and play gun games (waiting
  on the guns)".
- **Replaces:** none.
