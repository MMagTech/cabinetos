# Arcade saves travel in RomM's form, every file of them

- **Decided:** All of an arcade game's save goes to RomM: the board's memory, the high scores and a player's card. It travels as RomM takes an arcade save and as Sigil packs one, the emulator's own files under their own names: one file as it is, several as a zip with no folders in it. MAME 0.289's, whose names the board chooses, is a zip of its folders, as Model 2's and Model 3's are of theirs. An emulator's own settings and a hard disk's changes are no part of it and stay on the console.
- **Date:** 2026-11-25
- **Why:** RomM has no shared form for arcade yet and takes the files the emulator wrote (rommapp/romm#5175; RomM 5.5.0-beta.1's code). Sigil's arcade page counts board memory, high scores and memory cards as the save, and names the files for FinalBurn Neo and MAME 2003-Plus. So this is their form, not one of the console's own, and the reason to wait is gone. FinalBurn Neo's high scores are in Sigil's count but not yet in its list of files; for MAME 0.289, Naomi and Atomiswave Sigil says nothing, and RomM's rule stands. A setting changed in a board's own test menu is in the board's memory, so it follows the player; that was already so for the boards whose memory travelled.
