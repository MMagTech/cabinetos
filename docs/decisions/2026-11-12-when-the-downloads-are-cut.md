# When the downloads are cut, and which file goes up

- **Decided:** The installer ISO and the portable file on R2 are cut again together, from the image on `latest`, once each month's base update has merged, and at once when a change fixes the installer, first run or privacy. Each goes up from the finished run that was checked, never from a new build: `build-disk.yml`'s `iso_run` takes the ISO from a run, as `portable_run` already took the portable file, and `publish`, which built and published the ISO in one run, is gone. Nothing builds or publishes them on a merge or a schedule: the base update's pull request ends with the step as a checkbox (`ci/check-base-update.sh`), and MMagTech runs the publish.
- **Date:** 2026-11-12. When to cut the ISO was agreed on 2026-11-02 and not written down; the portable joins it here.
- **Why:** A new console does not update by itself: its weekly check is off until the player turns it on (`frontend/src/updateflow.cpp`), so an old download keeps a new player on an old image, with its old faults, until they find System update. Nothing said when to cut, and the ISO on R2 stayed on 2026.11.03 for ten days while the sound rule (#656), first run's time zone (#649) and the on-screen keyboard (#671) changed. The base update is already a monthly sitting with a checklist, so the reminder rides it. A file is checked before it goes up: CI boots the portable, and the ISO is installed in the VM (`tools/installer-vm.sh`), since CI never starts an installed ISO; building again to publish would put up bytes nobody checked. By hand rather than on the merge, because an upload that fails, or puts up a bad file, with nobody watching would leave the old file or the bad one up unnoticed.
- **Numbers:** #705, "Downloads: the base update says when to cut them, and the ISO goes up from the run that was checked"; #658, "The portable file can go on the download page without being built again"; #656, "Sound: one rule on every PC, read from what each output reports"; #649, "Portable install, step 2: running from a USB drive (PC's drives hidden, drive filled, time zone asked)"; #671, "On-screen keyboard: a held direction repeats, Shift locks, and the field has a cursor".
- **Replaces:** building the ISO once per release (the comment at the top of `build-disk.yml`, and docs/WORKING.md), and `publish` for the ISO in [portable-download](2026-11-05-portable-download.md).
