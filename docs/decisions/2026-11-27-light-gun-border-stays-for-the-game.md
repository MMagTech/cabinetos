# The light gun's border stays up until the game ends

- **Decided:** in a light-gun game, the border (#575 rule 9) goes up as soon
  as a gun is plugged in, and stays until the game is left, even if every gun
  is unplugged in between. The picture is drawn inside it the whole time.
- **Date:** 2026-11-27
- **Why:** the border shrinks the picture. On the first day with the guns
  (2026-11-27) a gun dropped off USB by itself 16 times in one port, and
  plugging one gun in knocked the other off; taken down with the gun, the
  border would make the picture jump under the other player each time, and
  leave the returning gun with no border to find. Rule 6 says unplugging
  breaks nothing and the game carries on. A gun game played with no gun is
  rare: an arcade gun game starts only while a gun is plugged in (rule 8).
- **Numbers:** #575, "Sinden light guns: plug in and play gun games (waiting
  on the guns)".
- **Replaces:** none.
