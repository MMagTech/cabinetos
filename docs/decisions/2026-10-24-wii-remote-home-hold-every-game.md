# Holding HOME on a Wii Remote is the way out of every game

- **Decided:** Holding HOME on a Wii Remote for a second opens the pause menu in every game, not only Wii games. A Remote still plays only Wii games. The console doesn't grey out games or refuse to start them when only a Remote is on.
- **Date:** 2026-10-24
- **Why:** With only a Remote on, a player could start a game the Remote can't play and could leave only by the power button (a Discord report, 2026-10-23). Two other fixes were weighed. Greying out games with no pad on would grey the whole library whenever a pad sleeps. A "Turn on a controller" toast at every start adds a rule about which controllers play what, and that rule must stay right as controllers change (Remote Play devices, keyboards) or it blocks someone who could play. The hold has no such rule, and Remote players already try it, because a Wii works that way.
- **Numbers:** #571, "Holding HOME on a Wii Remote opens the pause menu in every game".
- **Replaces:** none.
