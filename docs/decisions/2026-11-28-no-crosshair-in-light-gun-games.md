# No crosshair in light gun games

- **Decided:** the console never adds a crosshair to a light gun game, and every emulator's own crosshair stays off. Each game looks as its cabinet did: a game that draws its own cursor shows it, and one that does not shows none. To be reopened only if a sound way to tell those games apart is found.
- **Date:** 2026-11-28
- **Why:** a crosshair switch was wanted for children and beginners. But arcade games built for mounted guns (Alien 3, Operation Wolf, Space Gun) draw their own cursor, and a console crosshair would double it. No emulator records which games draw one: FinalBurn Neo's and MAME's crosshair settings treat those games and true light gun games alike, so only a list kept by hand could tell them apart, and the console keeps no per-game lists. One switch in Settings would be wrong in every game with its own cursor, and the pause menu is not a place for settings.
- **Numbers:** #575, "Sinden light guns: plug in and play gun games (waiting on the guns)".
- **Replaces:** none.
