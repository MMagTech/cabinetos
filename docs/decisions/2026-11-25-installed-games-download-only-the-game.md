# PS3, Vita and Xbox games download only the game

- **Decided:** A game that is installed before it runs (PS3, PS Vita, original Xbox) downloads only the files RomM marks as the game, the rule every other system follows. Its updates and DLC stay on the server until #181 is built. What a console already installed stays.
- **Date:** 2026-11-25
- **Why:** One rule on every system. Taking everything half worked: an update could stop a disc game from starting, DLC was downloaded and never seen, and one package that would not install failed the whole game. Keeping updates for PS3 downloads alone was the other choice; it worked only while a game was bigger than its update. The cost: on a fresh install, a PS3 download with an update beside it plays its original version until #181.
- **Numbers:** #749 "PS3 and Vita games download and install files RomM marks as updates or DLC"; #181 "Updates and DLC as separate files in RomM (Switch, PS3, Xbox 360)".
- **Replaces:** none.
